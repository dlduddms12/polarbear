# 북극곰 구출대작전

참여수업용 터치스크린 게임입니다.
얼음칸 퀴즈를 하나씩 풀면서 엄마 북극곰을 한 칸씩 옮겨, 기다리고 있는 아기 북극곰을 찾아 주세요.

## 실행하기

이 저장소는 GitHub Pages로 바로 실행됩니다.

- 주소: https://dlduddms12.github.io/polarbear/
- 크롬 등 웹 브라우저에서 위 주소를 열면 됩니다.
- 인터넷(와이파이)이 연결된 상태에서 실행됩니다.

## 노는 방법

1. 첫 화면을 터치하면 전체 화면으로 바뀌고 게임판이 나옵니다.
2. 게임판을 한 번 터치하면 엄마 북극곰의 편지가 나오고, 편지 아래의 **화살표 버튼(▶)** 을 누르면 게임이 시작됩니다.
3. 반짝이는 얼음칸의 `?` 를 터치하면 "나는 누구일까요?" 퀴즈가 나옵니다.
4. 동그라미 속 동물 그림자와 힌트를 보고 맞혀 본 뒤 **[정답]** 을 누르면 정답 그림이 나옵니다.
5. **[게임판으로]** 버튼이나 화면 아무 곳을 터치하면 게임판으로 돌아갑니다.
6. 엄마곰을 손가락으로 끌어서 다음 얼음칸으로 한 칸 옮깁니다.
7. 12칸을 모두 지나 아기곰에게 데려다주면, 엄마곰이 고마움의 말풍선으로 인사합니다.

## 선생님용 단축키 (키보드)

| 키 | 기능 |
|----|------|
| R | 처음 화면으로 (게임 다시 시작) |
| F | 전체 화면 켜기 / 끄기 |
| F5 | 새로고침 (처음부터 다시) |

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 게임 시작 파일 |
| `assets/` | 게임 코드와 이미지 |

※ `index.html` 을 더블클릭해서 여는 방식은 지원하지 않습니다. 반드시 웹 주소로 열어 주세요.
